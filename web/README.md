# 条件考古学网页 · 小范围试用版 v0.1.1

**ChatECNU用户：直接阅读[ChatECNU接入步骤.md](ChatECNU接入步骤.md)，双击“启动ChatECNU.cmd”，在本机终端输入学校API令牌即可。** 地址与ecnu-max已预填；读取模型列表验证后启动，不保存令牌。尚未用真实学校令牌测试。

这是 Skill v1.0.0 的网页入口，与最终 A2 海报的版本和端口标注一致。包含中文界面、四科预置示例、真实模型服务端适配器、报告下载与问题记录。ChatECNU接口适配已实现，真实令牌调用尚未验证；本机自动化浏览器交互检查尚未完成，当前为小范围本机试用版。

本机工程检查状态见项目根目录 `reports/current/`；既有研发证据按原批次保存在历史报告目录。页面支持单项覆盖统计和标准/扩展组合范围选择。配置存在不等于真实分析已测试成功。

## 现在怎么打开

Windows 双击“启动网页.cmd”，保持窗口打开，然后浏览器访问 **http://127.0.0.1:8765**。本包只需要 Python 3.11 或更新（本机验证3.12.8），不用安装前端开发工具或额外Python依赖。其他系统在此文件夹运行 `python server.py --port 8765`。

不能双击static/index.html代替启动服务器：四科示例和真实分析接口都需要本地服务。

## 页面已经有什么

1. 输入完整定理，选择数学分析、高等代数、实分析或复分析。
2. 四科“查看本科示例”：分别展示内部零点、正定二次型、Lebesgue控制收敛、Liouville定理。示例是预先编写的解析，始终有示例标签，不收费、不冒充模型新生成结果。
3. “定理与假设”：原命题、对象、定义、量词、原子化假设和拆分结论。
4. “逐项删减”：点选条件，查看具体反例、每条保留/替代条件核验、被删条件违反的论证和目标结论失效；区分不可删、可删、被推出、组合、类型、未判定和原命题有误。
5. “条件关系”：每条关系附保留背景、论证和干预来源，不声称已找到全部最小条件集。
6. 下载包含原始输入、版本、模型、用量、各项证据和未完成内容的Markdown及JSON报告；下载本地问题记录供后续复核。反馈不会自动发给别人，不自动更新策略或变成金标准。
7. 歧义澄清表单、截断/拒绝/服务错误提示，以及未探索范围。

输入自己的新定理必须点击“开始真实分析”。“查看本科示例”只加载本科预置题，会替换输入框，不能用它代替新题推理。

## 如何接通真实分析

网页通过 ChatECNU 的 Chat Completions 接口发送分析请求。服务端加载 Skill 主文件、判定协议、策略库、验证规则、输出规范和黎曼复合回归案例，不发送开发/验证/盲测答案。结构检查只能核验报告格式和义务覆盖，不能证明数学正确。

真实分析请双击 `启动ChatECNU.cmd`，按启动窗口说明在本机输入令牌并选择当前账户获准使用的模型。令牌不会写入项目文件。不要把真实令牌发到聊天或提交到 GitHub。

默认输出上限12000、单请求等待120秒，并发2；可通过CA_WEB_MAX_OUTPUT_TOKENS、CA_WEB_TIMEOUT_SECONDS调整。12000参考原Skill实验，是配置起点，不保证新模型/网页格式在此预算全部完成。生成者自检只算数学论证；当前没有独立AI二次审阅、计算执行、人工或形式化工具。

建议接通后先测：连续函数内部零点、实对称正定矩阵、完整控制收敛定理、Liouville定理；再测仅给“Lebesgue收敛定理”是否澄清，及错误原命题“整函数导数处处非零则单射”是否识别错误。逐条复核保留条件，不把返回JSON成功当数学通过。

当前没有实际向模型发送请求，也没有模型费用记录；本包测试里的服务回答是明确标记的工程测试数据，不是模型分数。

## 给老师、同学试用

先在你自己的电脑确认页面和真实分析可用，再选择一种方式：

- **同一局域网临时试用**：设置一个试用访问码和你电脑的局域网IP。保持服务运行，同学访问你的IP，不能访问他们自己电脑的127.0.0.1。

```powershell
$env:CA_WEB_ACCESS_CODE="设置仅向试用者提供的访问码"
$env:CA_WEB_ALLOWED_HOSTS="填写你电脑的局域网IP"
python -X utf8 server.py --host 0.0.0.0
```

CA_WEB_ALLOWED_HOSTS写IP或域名，不写http前缀或端口。需要防火墙允许8765端口，临时局域网HTTP没有传输加密，仅适合受信网络。当前服务默认只绑定本机；不会自动修改防火墙或公开到互联网。访问码由试用者在页面“模型服务”中输入，仅存页面内存。

- **异地固定网址**：部署到有HTTPS与反向代理的小型服务器，设置试用访问码和允许的域名、模型配置。当前Python内置服务器仅用于本机或受控试用；公开长期服务应替换为生产后端，并增加持久化限额、管理员用量统计与按需账号。本包没有替你注册域名、租服务器或公开部署。

默认每IP十分钟8次提交、同时最多2个模型请求。它们是单进程临时限制；重启会清空，同一网络可能共享IP，不是付费服务的完整额度系统。

## 数据与界面边界

- 浏览器不接触模型密钥；服务端不把原始服务错误、密钥、Skill源文件或配置路径暴露给访问者。
- 服务端不持久化定理和报告、不输出访问日志。真实分析仍会把输入发送到管理员配置的模型服务；Responses路径设置store=false，聊天路径不添加未确认支持的store字段。服务商保存政策仍须单独确认，不能据此保证服务商不留存。
- 只有用户点击下载时才落地保存报告/问题记录；网页不自动保存历史。刷新会丢失当前结果及访问码。
- 当前公式以Unicode数学文本呈现，支持上下标、集合、箭头和简单积分；复杂LaTeX排版编辑器、图形函数可视化和自动计算尚未接入。
- 当前RSI在原研发包里离线执行。网页问题记录经AI复核后才能进入开发证据，不能直接更新线上Skill。评分不以用户点赞或模型自报置信度代替数学核验。

## 验证

```powershell
python -X utf8 -m unittest discover -s tests -v
node --check static/app.js
```

tests/test_ui.cjs是Playwright浏览器测试，使用显式测试数据模拟已接入模型、歧义和失败路径。准备Playwright和浏览器后可以运行；浏览器自动化库不是日常使用依赖。CA_WEB_TEST_BROWSER可指定浏览器可执行文件，PLAYWRIGHT_MODULE可指定playwright模块路径。当前环境浏览器启动受限，尚未完成这些交互测试和截图检查。详见reports中的真实记录。
