怎样读这份报告

先看“定理与假设”，确认模型理解的对象、定义和量词与你的教材一致。

  1. 选择一个条件：查看删掉或弱化它以后，命题发生了什么变化。
  2. 检查具体对象：反例必须仍满足全部保留条件，同时推翻指定结论。
  3. 分清不同判断：不可删、删后仍成立、被其余条件推出、需要重写定义和未判定具有不同含义。
  4. 查看分析范围：没有找到反例不表示冗余；未探索的组合会单独列出。

示例按钮只加载当前科目的预置题，不会把你自行输入的定理当成已经分析。

证据与使用边界

Skill 是分析流程和策略库，需要由模型执行。网页本身不是数学证明器。

  • 预置示例：事先写好的数学解析，用于说明操作。
  • 真实分析：配置服务端模型后，对你的定理生成数学论证；它可能出错。
  • 局部计算、独立 AI 复核、人工审阅、形式化验证：当前网页没有运行这些步骤，不会把它们显示成已通过。

本页不自动改写 Skill。下载的问题记录可用于后续复核，不能直接触发策略更新或变成金标准。

支持数学分析、高等代数、实分析和复分析。对困难题允许给出“尚未判定”。
