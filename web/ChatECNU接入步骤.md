# ChatECNU 接入与真实分析

本说明适用于 **Skill 1.0.0 / Web 0.1.1**，与最终 A2 海报标注的版本、端口一致。网页地址为 8765。网页仅面向数学分析、高等代数、实分析、复分析；结构或工程通过不能代替数学核验。

## 启动网页

1. 进入本项目的 `web` 文件夹，双击 **启动ChatECNU.cmd**。
2. 黑色窗口提示输入令牌时，在本机粘贴 ChatECNU API 令牌并按回车。输入不显示字符是正常的。
3. 程序会向 ChatECNU 读取可用模型列表，确认令牌能访问预设的 `ecnu-max`。该读取不是定理分析请求；此阶段不会提交定理。
4. 成功后访问 **http://127.0.0.1:8765/**，并保持启动窗口打开。

令牌只留在启动进程内存，不写入项目文件或聊天。不要把令牌发给 Agent、同学或提交到 GitHub。若模型列表不含 `ecnu-max`，先向平台确认模型调用名与权限；程序不会自动换成其他模型。

## 测一条新定理

在网页选择科目，输入完整定理，然后点击 **开始真实分析**。这一步会把定理和 Skill 指令发送给 ChatECNU，并消耗该令牌账户的 API 额度。点击“查看本科示例”只载入预置解析，不调用模型。

建议先用连续函数内部零点定理：

> 若 (f:[0,1]\to\mathbb{R}) 连续，且 (f(0)<0<f(1))，则存在 (c\in(0,1)) 使 (f(c)=0)。

返回后逐项查看被删条件、保留条件核对、目标结论失效和证据标签，并保存报告。模型输出和格式检查通过仍不等于独立数学复核；遇到无法确认的反例或定义，应标为待核验。

## 常见情况

| 现象 | 处理 |
|---|---|
| 页面打不开 | 确认启动窗口仍在运行，并访问 8765；关闭浏览器标签不会停止服务。 |
| 8765 被占用 | 保留正在使用的服务，联系维护者检查当前端口，不要结束来源不明的进程。 |
| 令牌或模型校验失败 | 到 ChatECNU 确认令牌有效、权限和模型名称；不要反复提交真实分析来试错。 |
| 开始分析按钮不可用 | 确认已使用 ChatECNU 启动程序且模型列表检查通过。 |
| 请求失败或返回不完整 | 保存错误和报告，不将失败记为成功；每次已发出的请求都可能消耗额度。 |

实际调用次数、模型返回用量和费用应以保存的报告及平台记录为准。当前维护候选尚无本轮 ChatECNU 真实调用结果，也没有新的能力评分或 RSI 收益结论。
