## 1. 精确定理与量词

对象约束 D：`(X,d)` 是度量空间，`f:X→R`，值域采用通常距离。

- H1：X 非空。
- H2：X 紧。
- H3：f 在 X 上连续。
- C1：f 一致连续，即对任意 ε>0，存在 δ>0，使任意 x,y∈X 满足 `d(x,y)<δ` 时都有 `|f(x)−f(y)|<ε`。

以下“不可删”均相对于保留其他条件的普遍命题而言。它不声称每一个一致连续函数的定义域都必须紧致。

## 2. 删除紧致性 H2

新命题：任意非空度量空间上的连续实函数都一致连续。

**数学判断：indispensable。新命题不成立。**

取 `X=R`、`d(x,y)=|x−y|`、`f(x)=x²`。

逐项验证：

| 义务 | 核对 |
|---|---|
| 对象约束 D | R 配通常距离是度量空间，平方函数是 R 到 R 的函数。 |
| H1 非空 | 0∈R。 |
| H3 连续 | 对任意 a∈R，`x²−a²=(x−a)(x+a)`；当 x→a 时乘积趋于 0。因此每点连续。 |
| 被删的 H2 确实失效 | `(-n,n)`（n 为正整数）构成 R 的开覆盖，任何有限子族的并都被某个有限区间包含，不能覆盖 R。故 R 不紧。 |
| C1 失败 | 取 ε=1。任给 δ>0，取正整数 n 充分大使 `1/n<δ`。设 `x=n`、`y=n+1/n`，则 `|x−y|=1/n<δ`，而 `|f(y)−f(x)|=2+1/n²>1`。故不存在可用于 ε=1 的统一 δ。 |

失效机制是：局部连续性允许 δ 依赖所在位置，定义域走向无穷时，平方函数的局部变化速度没有统一控制。

边界说明：紧致性对这条普遍保证不可直接删除，但它不是一致连续的必要条件。例如 R 上的恒等函数满足 `|f(x)−f(y)|=|x−y|`，一致连续。也不能据此推断所有非紧空间都存在同样的坏例子。

证据：mathematical_argument。没有调用计算工具，没有独立人工审阅或形式化证明。

## 3. 删除连续性 H3

新命题：非空紧度量空间上的任意实函数都一致连续。

**数学判断：indispensable。新命题不成立。**

取 `X=[0,1]` 配通常距离，定义

`f(x)=0`（x<1/2），`f(x)=1`（x≥1/2）。

逐项验证：

| 义务 | 核对 |
|---|---|
| 对象约束 D | 闭区间配通常距离是度量空间，分段定义对每个 x∈[0,1] 都给出唯一实数。 |
| H1 非空 | 0∈[0,1]。 |
| H2 紧 | 实直线中的闭有界区间紧；这里使用通常的 Heine–Borel 结论。 |
| 被删的 H3 确实失效 | 对 n≥3，`x_n=1/2−1/n` 属于区间，且趋于 1/2，但 `f(x_n)=0`，而 `f(1/2)=1`，故 f 在 1/2 不连续。 |
| C1 失败 | 取 ε=1/2。任给 δ>0，选 n≥3 且 `1/n<δ`，令 `x=1/2−1/n`、`y=1/2`。则距离小于 δ，函数值差恒为 1，违反一致连续性要求。 |

失效机制是：紧致性不能修补函数自身的跳跃。进一步，一致连续必推出每点连续：在任一点 a，把一致连续定义中的一个变量固定为 a 即得到连续性。因此这里连续性还有结论必要性方面的直接解释。

证据：mathematical_argument；其中紧致性核验引用标准数学结果，不是程序自动核验。没有独立人工审阅或形式化证明。

## 4. 删除非空性 H1

新命题：紧度量空间上的连续实函数一致连续，允许 X 为空。

**数学判断：removable；不标为 implied。**

若 X 非空，原 Heine–Cantor 定理适用。若 X 为空，存在唯一空函数 `f:∅→R`；任给 ε>0，取 δ=1，定义中的“对所有 x,y∈X”没有实例，条件空真成立，因此 f 一致连续。故允许空集后结论仍成立。

也可直接观察通常的紧致性证明：固定 ε>0，对每个 a∈X 用连续性选 `r_a>0`，使 `d(a,z)<r_a` 时 `|f(z)−f(a)|<ε/2`。有限选取覆盖 `B(a,r_a/2)` 后取有限个 `r_a/2` 的最小值，便得到统一 δ。空集情形单独取 δ=1 即可。

非空性不能由紧致性与连续性推出，因为空度量空间本身紧，空函数连续。所以这里是“可删除但不被其他条件蕴含”的例子。

证据：mathematical_argument。若用户采用“度量空间按定义必须非空”的教材约定，则 H1 是定义性约束；上述删除明确采用允许空度量空间的约定，结论对应允许空集后的合法改写。这一约定已明示，不影响紧致性、连续性两项反例。
