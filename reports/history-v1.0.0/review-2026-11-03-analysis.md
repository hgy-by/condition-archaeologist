## MA01 — pass

f为实值函数的罗尔定理版本正确。|x|在[-1,1]连续、端点值均1、区间有限非退化；删去可微性后，0不可微，其他点导数只能为±1，故没有导数为0的点。

原版未显式注明实值，0.2.0已补。反例与保留条件逐项成立。

## MA02 — pass

f(x)=x (0≤x<1), f(1)=0，在(0,1)导数恒1；f(0)=f(1)=0；0<1。仅右端点连续性失效；不存在内部导数0的点。

原版实值类型补充后通过。注意内部可微已蕴含内部连续，删去的是闭区间整体连续性。

## MA03 — pass

K=(0,1)在R中非闭，故不紧；1/2属于K，非空性保留。f恒等连续；对任意x∈K都能找到更大和更小的K中点，故不取最大、最小值。

原版把非空与紧致捆绑，现拆为H1紧、H3非空并只删除H1，修订正确。

## MA04 — pass

x^n在[0,1]连续。0≤x<1时x^n→0，在x=1恒1，故逐点极限f在1不连续。对每个n，上确界误差为1，所以非一致收敛。

原版干预仅写删除且replacement为空；现写逐点替代H2w及其独立验证，修订正确。indispensable按“不能用该弱化替代而保持保证”理解。

## MA05 — pass

任取x∈I，差商[f(x+h)−f(x)]/h趋于有限导数，因而有界，乘h→0可得连续。H1开区间、H2可微保持，H3被推出。

这是项目自编冗余练习，原结论虽显然仍可检验冗余，不应冒称逐字教材定理。

## MA06 — pass

删除A⊂[0,1]，保留非空有限实数集。列A={a1,...,ak},k≥1，取M=max|ai|，则|a|≤M。无法推回A⊂[0,1]，标签removable恰当。

## MA07 — pass

单删任务正确。

## MA08 — pass

同时删除区间包含与有限性，取A=N。A非空但无上界，原两个被删条件都不满足。在保留H1的背景下已找到联合失效证据。

MA06和MA07分别证明单删可行，MA08证明双删失败；三题共同支撑当前组合关系，不推广为所有依赖图。

## MA09 — pass

## RA01 — pass

## RA02 — pass

E_n=[n,∞)为Lebesgue可测递减集，每项测度∞，交集为空、测度0。所以删除首项有限测度后，从上连续等式失效。

## RA06 — pass

R上f_n=1_[n,∞)，对每个固定x最终n>x，故逐点（从而a.e.）趋0。ε=1/2时超水平集[n,∞)测度∞，不趋0，故不依全空间测度收敛。
