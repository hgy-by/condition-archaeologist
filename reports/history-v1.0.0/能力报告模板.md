# 下一轮真实实验报告填写清单

这是一份报告字段规范，不包含模拟成绩。没有实际结果的字段写未运行及原因，不得填示意分数。

1. 研究问题：触发失败、可迁移修改、预期受益、可能回归；区分维护发布与RSI收益。
2. 数据：题目ID、科目、家族与机制、开发/验证/盲测池、答案暴露情况；说明是否见过变式。
3. 冻结材料：运行目录、版本摘要、模型返回名称、服务来源、采样、上下文、权限、每题预算、重试规则及实际次数。
4. 数学复核：每个对象类型、保留/替代假设、被删条件、目标否定、冗余证明、依赖背景、未知项；AI/计算/人工/形式化分别登记，审阅者是否知道组别。
5. 指标：原文假设precision/recall、反例precision/discovery、implied/removable按类、组合、完整任务数学/协议、未知与证据诚实性、迁移及请求/耗时/token/实际账单。每个比例给分子分母；未评写null。
6. 比较：同题同资源配对、家族重抽样区间、失败与截断、消融实际删除部分、重复次数；不将不同预算成绩拼接。
7. 决定：门槛通过/拒绝的真实原因、候选和基线摘要、AI或人工接纳来源、备份和回滚路径；未证实收益明确写未证实。
8. 局限：数学审阅缺口、共同错误、机制泄漏、未跑实验和能支持的最窄结论。
