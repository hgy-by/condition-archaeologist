## 定理与约定

固定有限整数n≥1，A⊂R^n；若A闭且有界，则A紧。

R^n使用通常欧氏距离和拓扑；空集允许，n=0情形单独讨论。紧致按每个开覆盖存在有限子覆盖定义。有限维与欧氏度量属于本版本的对象背景。

H1：A在R^n中闭  
H2：A在R^n中有界  

结论：A紧致

## F-MA-closed：删除 H1

判断：indispensable

对象：n=1，A=(0,1)

保留假设核验：

H2：对每个x∈A，|x|<1，故有界。  

论证：A非闭。开集U_m=(1/m,1)，m≥2，覆盖A；任取有限个，只能覆盖(1/M,1)，M为这些m的最大值，因此不能覆盖全部A。

失效结论：A有开覆盖而无有限子覆盖，故非紧。

## F-MA-bounded：删除 H2

判断：indispensable

对象：n=1，A=R

保留假设核验：

H1：R是R自身的闭集。  

论证：A无界。U_m=(−m,m)，m≥1，是R的开覆盖；有限子族的并为某个(−M,M)，不能覆盖R。

失效结论：R非紧。

## F-MA-finite-dimension：删除 

判断：type_constraint

对象：改写到无限维Hilbert空间ℓ²，取闭单位球B。

保留假设核验：

H1：在改写空间中，范数连续，B={x:||x||≤1}是闭集。  
H2：B中元素范数均≤1。  

论证：有限维不是hs中的独立可删条件，原命题对象固定为R^n。改写命题为“任意Hilbert空间的闭有界集紧”后，该命题失败：标准正交序列e_k均属B且任意两项距离√2，所以不存在收敛子列；度量空间紧致必序列紧，因此B非紧。此结果只针对明确改写的命题。

边界：未把改变对象类别记为原命题的普通删条件成功。

## 使用接口观察

对象空间必须先固定。闭性依赖环境，紧致和有界也依赖拓扑/距离。没有以“非紧等于不完备”解释本题。
