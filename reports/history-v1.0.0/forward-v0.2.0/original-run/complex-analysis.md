# 复分析前向运行：恒等定理

本报告是本次使用 Skill 实际完成的 AI 前向推理，不是人工审阅、形式化核验或正式盲测得分。

## 定理与约定

若Ω⊂C是非空连通开集，f在Ω全纯，且存在互异零点z_n→a∈Ω，则f在Ω恒零。

全纯按开集上的复可微定义；零点聚点是互异零点的聚点，且必须属于Ω。非空性单列以检查冗余。

H1：Ω为开集  
H2：Ω连通  
H3：f:Ω→C全纯  
H4：存在互异零点z_n∈Ω趋于a∈Ω  
H5：Ω非空  

结论：对每个z∈Ω，f(z)=0

## F-CA-connected：删除 H2

判断：indispensable

对象：Ω=D(0,1)∪D(3,1)，左盘f=0，右盘f=1。

保留假设核验：

H1：两个开圆盘的并为开集。  
H3：全纯是局部性质，每一点的邻域内f均为常数。  
H4：z_n=1/(n+2)∈左盘，互异且趋于a=0∈Ω，全为零点。  
H5：0∈Ω。  

论证：两个圆盘不交，所以Ω不连通。f在右盘恒1而在左盘恒0。

失效结论：f并非在Ω恒零。

## F-CA-holomorphic：删除 H3

判断：indispensable

对象：Ω=D(0,1)，f(z)=Im z（视作复值函数）。

保留假设核验：

H1：单位盘开。  
H2：单位盘连通。  
H4：z_n=1/(n+2)为互异零点，趋于域内0。  
H5：0∈单位盘。  

论证：f在0沿实轴差商为0，沿纯虚轴差商为1/i=−i，故不可复微。f(i/2)=1/2≠0。

失效结论：零点有域内聚点，但f不恒零。

## F-CA-internal-accumulation：删除 H4

判断：indispensable

替代条件：存在互异零点z_n∈Ω趋于某个a∈闭包Ω，不要求a∈Ω。

对象：Ω=C\{0}，f(z)=sin(π/z)。

保留假设核验：

H1：穿孔平面开。  
H2：穿孔平面路径连通。  
H3：1/z在Ω全纯，sin为整函数，复合后全纯。  
H5：1∈Ω。  
H4w：1/n→0，且0∈闭包Ω。  

论证：z_n=1/n是互异零点，趋于域外边界点0。f(2)=sin(π/2)=1，所以不恒零。这个非零全纯函数的零点在域内无聚点：可直接求得零点为1/k，k为非零整数，只向0聚集。

失效结论：仅有无限零点和边界聚点仍不足。

## F-CA-nonempty：删除 H5

判断：implied

保留假设核验：

H1：开性保留。  
H2：连通性保留。  
H3：全纯性保留。  
H4：a∈Ω（或者任一z_n∈Ω）已经推出Ω非空。  

论证：H4直接蕴含H5，所以非空性在此表述下冗余；无需搜索空域反例。

## F-CA-open-set：删除 H1

判断：type_constraint

保留假设核验：

H2：形式上保留连通。  
H3：在本题采用的定义中，“f在Ω全纯”要求Ω为开集，所以若原定义不变，H3已含开性。  
H4：形式上保留域内聚点。  
H5：非空保留。  

论证：在声明的定义下，开集性是全纯的类型前提。若把H3改为“f是某邻域全纯函数的限制”，则对象与结论都应重写；不把非开集直接代入普通全纯定义。也可按定义内含约束将H1视作定义性冗余，但需固定标注约定。

边界：type_constraint与implied的交界需要项目评分规范统一：本输出按协议将类型前提归入type_constraint。
