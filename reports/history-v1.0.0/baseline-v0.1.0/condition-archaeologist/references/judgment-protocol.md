# 判定协议 v0.1

原命题：∀x∈D，∧ Hi(x) ⇒ ∧ Ck(x)。为每个 Hi/Ck 分配稳定 ID。H 包含非空性、域、维数、可测性、映射是否自映射等隐含条件；定义和假设分列，避免把“在 X 上定义”误作“像落在 X”。

删除集合 S 的任务是检验 ∀x∈D，∧(i∉S) Hi(x) ⇒ Ck(x)。有效反例证明对象属 D、每个保留 Hi 成立、¬Ck；对单删还应核对 ¬Hi。弱化任务写出 H'i 并验证。目标量词的否定必须准确：否定“存在唯一”可以没有解或至少两个；两类分别说明。

数学状态：
- indispensable：已给有效反例，故在当前其他条件背景下不可删。
- removable：删后结论成立，给完整适用论证。
- implied：其余条件推出目标条件，给推导。
- joint：在指定联合干预背景下给出有效证据。单删尚未解决不能自动判 joint。
- type_constraint：需重定义对象类别或命题；可给改写后分析，但不得当原任务已解决。
- unresolved：预算内证据不足；列缺口及下一步。搜索失败不等于逻辑独立性。

分析一个明显错误的原命题，先给满足全部假设的反例并报告 statement_issue，不继续把错误归因于某个删除条件。

证据状态独立于数学状态：candidate、mathematical_argument、partial_computation、human_reviewed、formal_checked、unresolved。formal_checked 要有证明源码、工具版本、命题对应关系和实际通过日志。human_reviewed 要有独立审阅者与逐项记录。允许多个证据类型同时存在。

互相推出或重复的条件用联合干预定位。例如 A、B 均确保性质 P，单删仍有 P，双删才失效。报告的是给定背景下的依赖，不声称找到所有最小条件集。非单调或改变对象类型的干预需另写命题。

结论拆分：存在性、唯一性、有界性、收敛性、收敛速度分别核验。只破坏其中一项就标注具体 Ck，不夸大其余结论的失效。
