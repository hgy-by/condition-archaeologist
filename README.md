# 条件考古学 · Condition Archaeologist

输入一条定理，逐项删去或弱化假设，构造反例，并逐条说明保留条件为何仍成立、指定结论为何失效。支持**数学分析、高等代数、实分析、复分析**，重叠主题可交叉标注。

## 这个 Agent Skill 做什么

`condition-archaeologist` 是一套供 AI Agent 遵循的数学分析工作规范。它不是独立运行的定理证明程序：Agent 读取 `skill/SKILL.md` 和引用规则后，按统一步骤分析用户给出的完整定理。网页将这套规则与用户输入一起发送给 ChatECNU 模型服务。

**项目成员：侯冠伊、徐炳涵**

每项任务的核心流程是：

1. 固定原定理的对象、定义、量词、假设和结论；发现原命题本身有误时先单独报告。
2. 逐项删除或明确弱化假设，并为每个保留条件列出核验义务。
3. 搜索反例，按定义核验对象、全部保留条件、被删条件和结论失效；关键计算若矛盾，撤回该候选。
4. 对有限范围内有关联的条件做组合干预，记录条件依赖及尚未探索的部分。
5. 按证据等级报告结果；未找到反例不等于条件冗余，证据不足时保留“尚未判定”。

输入请尽量给出**完整命题**，包括定义域、值域、函数类型、量词和所用的可积/收敛定义。可输入普通文字、Unicode 数学符号、Markdown 或 LaTeX 源码；网页把它们作为文本传给模型，复杂 LaTeX 不保证排版渲染。输出是按原命题、各假设干预、保留条件核验、结论失效、依赖关系和未完成事项组织的报告。模型给出论证不等同于独立人工审阅或形式化证明。

当前交付版本：**Skill 1.0.0 / Web 0.1.1 / 本地端口 8765**。维护中补充了反例自洽性核验规则和黎曼可积复合问题的专项案例；既有历史实验数据仅适用于其原测试批次，不是本次维护的新能力成绩。

这是四科数学学习辅助工具，需要模型执行；不是任意定理的自动证明器。无法找到反例时会保留“尚未判定”，不能因此认定条件冗余。

## 适用范围与限制

- 覆盖数学分析、高等代数、实分析、复分析；高等代数首版重点为线性代数与多项式，不能据此宣称覆盖所有数学分支。
- 报告由 ChatECNU 模型生成，网页会检查报告结构和核验步骤是否齐全；结构检查不能证明数学结论正确。重要结论仍需按用途进行数学复核。
- Skill 提供有限的参考案例与反例策略，不保证每条定理都能找到反例或给出完整判定；超出分析预算的条件会列为未完成。
- 当前项目没有形式化证明器，也没有证据证明维护中的 RSI 流程能稳定提升模型能力。

## 先体验网页

### Windows启动
Windows 在项目文件夹的 `web` 子文件夹中双击 `启动网页.cmd`，保持窗口打开，在浏览器访问 `http://127.0.0.1:8765/`。启动脚本会根据自身位置找到网页目录，整个项目文件夹可以放在任意位置或移动。四科示例免费读取本地解析；分析新题需要配置模型。

使用 ChatECNU：双击 `web/启动ChatECNU.cmd`，**只在本机启动窗口输入学校令牌，不发到聊天或提交代码**。该启动脚本同样从自身位置运行；整个项目文件夹可以移动。首次读取模型列表；只有提交真实分析才生成模型回答并消耗额度。令牌不写入项目文件。

### macOS（Mac）启动

将完整项目文件夹放在 Mac 上任意位置；保留 `skill/`、`web/` 等目录，不要只复制 `skill/`。项目根目录提供两个 `.command` 启动文件，它们会根据自身位置找到项目目录，因此移动整个项目文件夹后仍可使用。

首次使用时，打开“终端”，输入 `cd `（`cd` 后留一个空格），再将项目文件夹从 Finder 拖入终端窗口并按回车。然后运行一次：

```bash
chmod +x "启动网页.command" "启动ChatECNU.command"
```

之后可在 Finder 中双击 `启动网页.command`，查看四科内置示例；保持终端窗口运行，在浏览器访问 `http://127.0.0.1:8765/`。也可以在项目根目录的终端运行 `./启动网页.command`。

网页运行需要 Python 3.11 或更高版本。要进行 ChatECNU 真实分析，双击 `启动ChatECNU.command`，或在项目根目录的终端运行：

```bash
./启动ChatECNU.command
```

按终端提示在本机输入 ChatECNU 令牌。真实分析会调用模型并消耗账户额度；不要把令牌写入项目文件或发到聊天中。结束服务时，在对应终端窗口按 `Control+C`。

网页默认使用海报标注的 8765。需要手动指定端口时，在项目根目录运行：

```powershell
python -X utf8 web/server.py --port 8765
```

示例地址为 `http://127.0.0.1:8765/`。要在该端口使用 ChatECNU，运行 `python -X utf8 web/launch_chatecnu.py --port 8765`，在本机窗口输入令牌。

网页提供两种范围：标准最多8个单项、1个组合；扩展最多8个单项、3个组合。每项最多尝试3类策略。未处理条件、未判定条件和已分析条件分别列出；“已分析”不等于“数学已核验”。

## 在 Agent 中使用 Skill

完整运行目录是 `skill/`，应整体复制，不能只复制 SKILL.md。支持本地 Skill 的客户端可先比较：

```powershell
python -X utf8 scripts/install_skill.py
```

确认目标正确后安装：

```powershell
python -X utf8 scripts/install_skill.py --install
```

已有同名目录会先保存完整旧版备份。安装需要本机目标目录写权限；本轮交付未覆盖你已安装的旧版。其他 Agent 可直接读取 `skill/SKILL.md` 及按需引用的文件，不保证不同客户端有相同的自动触发机制。

可发送：

> 请读取本项目 skill/SKILL.md，并按其中流程及引用文件分析以下完整定理。逐项核对保留条件，不把未找到反例视为冗余；注明实际证据层级。定理：……

## 本地检查与真实模型测试

网页运行只依赖 Python 3.11+ 标准库。完整工程检查另需 SymPy、PyYAML、Node.js。检查不会向模型发请求：

```powershell
python -X utf8 scripts/check_project.py
```

当前真实检查记录见 `reports/current/engineering-summary.json` 和相应日志。旧版原始输出、人工概括确认、AI审阅与失败实验完整保留在 `reports/history-v1.0.0/`，**旧分数不代表当前网页或 ChatECNU 的得分**。

准备8个公开验收任务，无模型费用：

```powershell
python -X utf8 evaluation/web_experiment.py prepare --suite smoke --out .runtime/ecnu-smoke
```

仅在确认预算后运行；要求在本机明确确认次数并输入令牌，无自动重试：

```powershell
python -X utf8 evaluation/web_experiment.py run --out .runtime/ecnu-smoke --max-calls 8
```

失败调用也计数，返回用量如实保存，价格未知则费用为空。输出结构合格后仍须数学审阅，不能直接产生数学分数。评分、基线、消融、RSI与盲测限制见 `docs/评测与RSI操作说明.md`。

## 文件位置

| 文件夹 | 内容 |
|---|---|
| `skill/` | 13个运行文件、17类反例策略、15个内置参考任务及证据状态 |

| `docs/` | 使用、架构、证据、提交与复核说明；history目录为历史材料 |
