# 现在开始使用

这是v1.0.0四科辅助使用版。当前不需要你继续填写人工审核txt或重新审核全部题目。原题册仍保留作历史材料；新回答默认由AI复核，必要歧义再确认。

1. 在Agent的新聊天中输入下方示例。
2. 提供完整定理，至少说明对象范围、关键定义和结论。
3. 阅读每项“保留条件核验”和“结论如何失败”；尚未判定表示需要继续研究，不能据此推断冗余。

```text
使用 $condition-archaeologist。
定理：f:[0,1]→R连续，且f(0)<0<f(1)，则存在c∈(0,1)使f(c)=0。
请逐条删除假设，验证保留条件，区分不可删、冗余及类型约束，说明证据层级。
```

若当前Agent不识别$名称：

```text
请读取附件中的condition-archaeologist/SKILL.md，并按其中的相对路径读取参考文件。
将它作为本次数学条件分析的工作流程。遇到定义歧义再问我；一般复核由AI完成并如实标注。
定理：……
```

完整JSON批量实验已实测的可行设置：输出上限12000、单请求等待120秒；不是对任意题目都足够的承诺。初轮6000预算存在截断，不能只提高等待时间解决输出上限问题。
