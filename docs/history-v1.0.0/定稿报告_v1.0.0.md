8道边界题及1道歧义题均通过AI复核和协议检查：4个错误原命题、1个类型约束、1个由其余条件推出、1个可以删除、1个单删成立合删失效、1个Lebesgue收敛定理名称歧义。冗余识别和组合分析据此有实际示例，但样本很少。

这些是已尝试任务上的内部确认，不是独立新盲测。复核AI知道组别和参考分析，存在共同错误风险。不得把本轮4/4或9/9写成普遍正确率100%。

尚未证明严格隔离迁移收益、跨模型稳定收益或两轮以上递归改进。后续若要作这些研究结论，应准备未用于规则设计的新家族、同配置多次重复，并满足最少8家族、成功率增益至少0.05、家族重抽样区间下界大于0、反例精确率不下降的原数值门槛。

## 使用与边界

安装位置为C:/Users/hougu/.codex/skills/condition-archaeologist。新聊天输入“使用 $condition-archaeologist。定理：……”并贴出完整定理；默认输出中文报告，只有要求时才输出JSON。若模型缓存旧内容，要求重新读取SKILL.md。

初次调用建议提供完整定理、对象范围和采用的定义。若只给“Lebesgue收敛定理”这类不唯一的名称，Skill会要求澄清，这是正确行为。对难例允许输出尚未判定，找不到反例不表示条件冗余。默认处理不超过8个单删、3个组合，每项不超过3类策略；超预算会列出剩余工作。

直接聊天使用不需要单独API或Python；让Agent读取运行目录即可。计算脚本需要Python及SymPy，研发评测需要相应依赖。自动批量实验还需要兼容Responses接口的账号与预算，不能靠压缩包继承本机密钥。

后续优先级：先在真实新定理上记录失败，再增加机制不同的新家族和多次配对实验，最后考虑扩大科目或用户理解诊断。当前没有必须由你补做的人工核验；出现定理定义不可合理确定或AI之间实质争议且无法解决时才向你确认。
