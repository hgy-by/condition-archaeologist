# 评测与RSI操作说明

## 本轮可以怎样运行

从项目根目录运行，prepare只读取输入和提示词，不发模型请求：

```powershell
python -X utf8 evaluation/web_experiment.py prepare --suite smoke --out .runtime/ecnu-smoke
python -X utf8 evaluation/web_experiment.py run --out .runtime/ecnu-smoke --max-calls 8
```

run会在本机要求明确确认总次数、隐藏输入令牌。8题包括四科定理、名称歧义、原命题错误、冗余识别和组合对角化迁移。源输入是evaluation/web_tasks.json，公开后只能称内部测试，不能称严格盲测。

其他方案：paired=8题×直接模型/完整Skill，共16次；ablation=8题×直接模型/完整Skill/去策略/去验证文档，共32次。准备时更换 --suite 和输出目录。可用较小 --max-calls 分段运行；上限是该目录**累计尝试次数**，失败也计数，不自动重试。计划摘要、请求提示词和响应保留以便核查。完成不足的配对不得只保留成功一侧比较。

RSI使用 --suite rsi --baseline-skill 冻结旧版运行目录，8题×新旧版共16次。当前只改了维护文档，不预设会有能力收益；若这些题已用于拟定规则，就不能用它们证明迁移收益，必须另外冻结未参与修改的新家族题目，再准备计划。重复比较公开旧题属于回归。

所有组共用任务、结构契约、模型名称、接口和输出预算，实际用量仍可能不同。去验证文档仅是文档消融，共同输出格式仍要求核验字段，报告时应写明这一局限。运行器只发送冻结消息，不读取种子或控制者答案，不自动接纳版本。

## 数学复核与打分

一次模型返回成功后，先按原始输入检查对象、量词、条件和结论是否完整；逐项复核每个反例的全部保留条件、替代条件、实际违反的被删条件及指定结论否定。不同于参考答案的反例可以成立，不能用字符串匹配判错。冗余/蕴含须有证明，未判定须指出真实缺口，关系图须有背景及来源。

审阅可由AI完成，必须逐项写理由并记录reviewer_type=ai，不称人工或独立人工审阅。更换模型或独立审阅是额外实验，需单独预算。若老师要求人工审核，或原命题含义/关键数学步骤仍有争议，再交人确认。运行器不自动产生数学评分；raw中的math_score保留为空，summary的结构通过数不能冒充数学分数。

原有评分工具继续可用：evaluation/lab.py（逐干预正式控制器）、ai_score.py（内部AI逐干预审阅）、final_score.py（完整定理逐项审阅），详细字段见evaluation/rubric.md、extended-review-rubric.md和历史已完成的审阅文件。final_score绑定旧experiment记录布局；新网页输出若接入它，应先建立新的冻结jobs与逐项审阅记录，并检验哈希，不能给旧审阅换上新输出继续计分。原final_experiment.py属于历史冻结实验，prepare中的旧计划哈希不会自动接受维护新版；新测试使用web_experiment.py。

至少报告以下指标及分母：

| 指标 | 核对方法 |
|---|---|
| 假设提取 | 用原题与审阅清单计算匹配数/应提取数及匹配数/实际提取数；不按编号字符串机械匹配 |
| 有效反例精确率 | 全部核验义务成立的反例数/声称成立的反例数；零声称时记未测而非100% |
| 反例发现率 | 找到有效反例的可反驳目标数/已审阅的可反驳目标数 |
| 冗余识别 | 判断与证明均正确的冗余/蕴含项目，并报告误报与漏报 |
| 组合分析 | 按指定删除集合和保留背景核验；没有单删证据不能声称最小协同 |
| 完整任务成功率 | 对象、提取、所有要求干预及证据边界均合格的任务数/全部计划任务数 |
| 不确定性 | 歧义题合理澄清、无证据不冒充已解决；拒答不能获得反例精确率满分 |
| 迁移 | 候选规则来源以外的家族分别报告；公开旧题只作回归 |
| 成本 | 全部尝试、失败、返回用量、耗时；价格未知则金额为空，不填0元 |

## RSI接纳

失败记录 → 查清失败类型 → 从已复核开发案例提出通用规则 → 临时副本修改 → 相同模型/权限/预算回归 → 隔离验证比较 → 记录接纳或拒绝 → 保存旧版以便回滚。

开发集、验证集、留出集依family_id及构造来源隔离，不能只随机拆题面。公开后或根据留出答案调参后，原留出只能降级为回归。最少报告配对任务完整性、家族数、精确率是否退化、成功率差和不确定区间；小样本或区间含零时写“尚未证明收益”。案例数量与策略数量增长不能替代效果证据。

AI内部比较使用ai_rsi.py及ai_reviewed_internal标签；正式独立评分使用lab.py的门槛，不混淆两类证据。工程维护发布可以不等RSI收益实验，但不能随发布宣称能力提升。

## 结果报告模板

每次新建报告，填写实际值；没有运行的内容明确写未运行：

- 版本、Skill树哈希、模型返回名称、服务、时间、任务来源与隔离状态。
- 计划/实际尝试数、失败数、完整配对数、预算、实际返回用量。
- 审阅者类型、证据文件及哈希、数学核验缺口。
- 上表指标及原始分子/分母；未知金额/未测分数不填模拟值。
- 基线/消融/新旧版差异、家族区间与适用限制。
- 接纳/拒绝决定、未解决问题及回滚路径。
